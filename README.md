# Store Business Intelligence Analytics & Dynamic Dashboards

**Role & Execution:** BI & Data Analyst.

- **System Scope:** Conducted comprehensive data analysis on retail Superstore transactional data to uncover key sales trends, profit drivers, and regional performance gaps.

- **Technical Implementation:** Performed data extraction and transformation using Power Query. Engineered dynamic Power BI dashboards featuring Star Schema data modeling, and multi-tier interactive slicers.

- **Tech Stack:** Excel, Python, Pandas, Data Modeling, Exploratory Data Analysis.
